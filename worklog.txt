
MANUAL WEBSITE

Task: Add images to the page
Decision: Originally wrapped <img> in <picture> then removed it given that I am not adding images of different resolution

Task: Create navigation
Decision: I used <nav> with simple <a> tags

Task: Add Headings and Paragraphs
Decision: I used <section> for all heading and related paragraphs. In index.html, I used <header> for headings.

Problem: Initially overused <br> elements to separate content and control spacing.
Solution: Decided to use <br> only where a line break was actually needed and used separate HTML elements such as <p> and <ul> when the content represented separate paragraphs or lists.

Problem: Initially used type="text" for the email field.
Solution: Changed it to type="email" so the HTML describes the expected type of information and the browser can provide basic email validation.

Comparison MANUAL vs AI assisted:

HOME PAGE

1. <main> element

What is different?
My manual version places the main content directly inside <body>. The AI version wraps the main content in a <main> element.

Why do you think the two versions are different?
I didn't initially think about using <main>, while the AI likely included it because it follows common semantic HTML practices.

Which solution do you prefer?
I prefer the AI solution.

Why?
<main> clearly identifies the primary content of the page and makes the HTML more semantic and easier to understand.

-------

2. Image and caption

What is different?

Why do you think the two versions are different?
I focused on the requirements of the assignment, which only required an image. I didn't think a caption was necessary. The AI added the <figure> and caption as an additional semantic element.

Which solution do you prefer?
I prefer my manual version.

Why?
The caption doesn't add any important information to this page, so I think it is unnecessary. The image already speaks for itself, and my version is simpler while still meeting the requirements.
